# 資産管理デスクトップアプリ 要件定義・設計仕様書

本ドキュメントは、Tauri + React (TypeScript) + Tailwind CSS を用いて開発するローカル完結型資産管理デスクトップアプリの要件定義書、基本設計書、および詳細設計書です。

---

## 1. 要件定義書

### 1.1 システム概要・目的
* **アプリ名:** 資産管理アプリ（仮称: AquaAsset）
* **目的:** 預金・株式・仮想通貨などの多様な資産を一元管理し、ユーザーによる手動入力で安全かつシンプルに月ごとの資産推移を可視化する。
* **プラットフォーム:** デスクトップアプリケーション（Windows 10/11 / macOS 対応）
* **ターゲット:** 個人の総資産およびポートフォリオのバランスを、外部送信を行わずローカル環境で安全に管理したいユーザー。

### 1.2 機能要件

#### ① ダッシュボード（トップ画面）
* **総資産額サマリー:** 全登録資産の最新評価額の合計表示、および前月比（増減額・増減率）の自動計算・バッジ表示。
* **ポートフォリオ配分表示:** カテゴリ別資産割合をビジュアル化（ドーナツチャート）。
* **資産推移グラフ:** 直近の資産推移をネオン調ラインチャートで表示。
* **主要資産グリッド:** 登録している主な資産のカード表示。

#### ② 資産一覧・管理機能
* **資産リスト表示:** 登録済み資産（預金、株式、暗号資産など）をテーブルまたはカード形式で一覧表示。
* **フィルタ・検索:** カテゴリ絞り込み、キーワード検索、並び替え機能。
* **評価損益・占有率表示:** 各資産ごとの占有率およびパフォーマンス表示。

#### ③ 資産の追加・編集機能（モーダル形式）
* **新規資産登録:** 資産名、カテゴリ（預金/株式/暗号資産/投資信託など）、現在の評価額の入力。
* **履歴入力・修正:** 過去の月別評価額の手動入力・修正機能。

#### ④ 月別資産推移・履歴分析
* **月別推移グラフ:** 月別総資産のバーチャート表示。
* **履歴データテーブル:** 過去の月別パフォーマンス（総資産額・前月比増減額・増減率）のリスト表示。

#### ⑤ 設定・セキュリティ
* **パスコードロック:** アプリ起動時のセキュリティ認証機能（任意設定）。
* **データバックアップ・復元:** ローカルデータベース（SQLite/JSON）のエクスポート・インポート。
* **テーマ設定:** スタイリッシュなダークモード（ネオンアクセント）基調のUI。

### 1.3 非機能要件
* **セキュリティ・プライバシー:** すべてのデータをローカル環境に保存（完全オフラインで動作可能）。金融機関API等の外部送信は行わない。
* **UI/UXデザイン:** サイバー感のある深みのあるダークモード基調、視認性の高い発光アクセントカラー（ネオングリーン）、スムーズなモーダル遷移。
* **応答性:** デスクトップアプリならではの軽量・高速な動作（Tauriの軽量性を活かした設計）。

## 2. 基本設計書

### 2.1 システムアーキテクチャ
* **アプリケーションフレームワーク:** Tauri (v2)
* **フロントエンド:** React + TypeScript + Vite
* **スタイリング:** Tailwind CSS + Lucide Icons（アイコン） + shadcn/ui コンポーネント
* **グラフライブラリ:** Recharts（または Chart.js + react-chartjs-2）
* **データベース・ストレージ:** SQLite（`tauri-plugin-sql` を使用）または LocalStorage（プロトタイプ時）

### 2.2 画面構成・ルーティング
全体をサイドバー＋メインエリアの2カラム構成とし、主要画面の切り替えおよびモーダルオーバーレイで操作を行います。

1. **`DashboardView`（ダッシュボード画面）**
2. **`AssetsView`（資産一覧画面）**
3. **`HistoryView`（推移・履歴分析画面）**
4. **`SettingsView`（設定画面）**
5. **`AssetModal`（資産追加・編集モーダル）**

## 3. 詳細設計書

### 3.1 データベース設計（SQLiteモデル）

#### ① `categories` テーブル（カテゴリマスター）
| カラム名 | 型 | 制約 | 説明 |
| :--- | :--- | :--- | :--- |
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | カテゴリID |
| `name` | TEXT | NOT NULL | カテゴリ名（預金, 株式, 暗号資産, 投資信託 など） |

#### ② `assets` テーブル（資産マスター）
| カラム名 | 型 | 制約 | 説明 |
| :--- | :--- | :--- | :--- |
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | 資産ID |
| `category_id` | INTEGER | FOREIGN KEY (categories.id) | カテゴリID |
| `name` | TEXT | NOT NULL | 資産名（例: ○○銀行, Bitcoin, NVIDIA Corp） |
| `created_at` | DATETIME | DEFAULT CURRENT_TIMESTAMP | 登録日時 |

#### ③ `asset_records` テーブル（評価額履歴）
| カラム名 | 型 | 制約 | 説明 |
| :--- | :--- | :--- | :--- |
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | 履歴ID |
| `asset_id` | INTEGER | FOREIGN KEY (assets.id) | 資産ID |
| `amount` | REAL | NOT NULL | 評価額（金額） |
| `recorded_at` | TEXT | NOT NULL (YYYY-MM) | 対象月（例: `2026-08`） |

---

### 3.2 データ計算ロジック

1. **総資産額 (Total Net Worth):**
   * 最新の `recorded_at` における全資産の `asset_records.amount` の合計値。

2. **前月比パフォーマンス (Monthly Performance):**
   * 当月総額 $M_{\text{current}}$ および 前月総額 $M_{\text{previous}}$ を取得。
   * 増減額 $\Delta M = M_{\text{current}} - M_{\text{previous}}$
   * 増減率 $\text{Rate} = \frac{M_{\text{current}} - M_{\text{previous}}}{M_{\text{previous}}} \times 100 \ (\%)$

3. **ポートフォリオ配分比率 (Portfolio Allocation):**
   * カテゴリごとの最新評価額合計 $\div$ 総資産額 $\times 100 \ (\%)$
