# 第4章 完成サンプル

第4章を終えた時点の作業フォルダです（第2〜3章のファイルも含む）。

| ファイル | 何をするか | 節 |
|---|---|---|
| `ma_signal.py` | 移動平均クロス（5日/25日）で売買シグナルを出す。終値は Yahoo Finance の公開データ | 4-3 |
| `ma_chart.py` | 価格・短期線・長期線＋売買サインの矢印をチャート画像に保存（matplotlib が要ります） | 4-4 |
| `scan_signals.py` | 主要100銘柄をまとめて判定し、サインが出た銘柄だけ表示する（0.3秒待ち入り） | 4-6 |
| `CLAUDE.md` | 第3章版に **「銘柄登録リストの上限50」の項** を追記したもの | 4-6 |

## 使い方

```
py ma_signal.py 7203
py ma_chart.py 7203        → chart_7203.png
py scan_signals.py
```

## 注意

- この章のスクリプトは kabuステーションAPI を使いません（日足の履歴が kabu API に無いため、借り物の日足で完結します）。
  だから100銘柄回しても「登録上限50」の壁に当たりません——**壁が出なかった理由**は本文4-6の種明かしを読んでください
- `ma_signal.py` の `fetch_daily_closes()` には第6章で使う `period` 引数（既定 `"1y"`）が付いています。第4章の動作は変わりません
