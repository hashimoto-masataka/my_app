# kabuステーションAPI 簡易マニュアル(このプロジェクトでよく使う操作)

出典: 同フォルダの仕様書 `kabu_STATION_API.yaml`(version 1.5、2026-09-02 取得)。
記述が食い違う場合は**仕様書を正**とする。エラーの意味は `エラーコード一覧.md` を参照。

- 接続先(本番): `http://localhost:18080/kabusapi`
- 接続先(検証): `http://localhost:18081/kabusapi`
- 認証以外のすべてのAPIは、リクエストヘッダー `X-API-KEY` にトークンを載せて呼ぶ

---

## 1. トークンの発行

```
POST /token
Content-Type: application/json

{"APIPassword": "APIパスワード"}
```

成功時のレスポンス:

```json
{"ResultCode": 0, "Token": "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"}
```

- `ResultCode` は 0 が成功。それ以外はエラーコード
- **トークンは有効である限り使い回せる。リクエストごとに発行する必要はない**(仕様書明記)
- トークンが無効になるタイミング(仕様書明記):
  1. kabuステーションを終了した時
  2. kabuステーションからログアウトした時
  3. **別のトークンが新たに発行された時**
  4. ※kabuステーションは早朝、強制的にログアウトする
- 注意: 3.があるため、**複数のスクリプトを同時に動かして各自がトークンを取り直すと、
  先に動いていた側のトークンが無効になる**。長時間動かすものは1つのトークンを共有する設計にする

## 2. 株価の取得(時価情報・板情報)

```
GET /board/{銘柄コード}@{市場コード}
X-API-KEY: (トークン)
```

例: 東証のトヨタ自動車 → `GET /board/7203@1`

市場コードの定義値(仕様書より):

| 定義値 | 説明 |
|---|---|
| 1 | 東証 |
| 3 | 名証 |
| 5 | 福証 |
| 6 | 札証 |
| 2 | 日通し(先物・オプション) |
| 23 | 日中(同上) |
| 24 | 夜間(同上) |

レスポンスの主なフィールド:

| フィールド | 意味 |
|---|---|
| `Symbol` | 銘柄コード |
| `SymbolName` | 銘柄名 |
| `CurrentPrice` | 現値(数値。取引時間外は最後に付いた値) |
| `CurrentPriceTime` | 現値時刻(日時文字列) |
| `ChangePreviousClose` | 前日比 |

注意(いずれも仕様書明記):

- **レスポンスの一部に null が出る場合は、その銘柄を「銘柄登録」(下記3)してから
  再度このAPIを呼ぶこと**
- **`Bid`系と`Ask`系のキー名は本来の意味と逆になっている**(公式が明記している既知の仕様)。
  `BidQty/BidPrice/BidTime/BidSign` と `AskQty/AskPrice/AskTime/AskSign` が対象で、
  実際の値は日本語の説明(買気配/売気配)のほうに準じる。板情報を使うときは要注意

## 3. 銘柄の登録と解除

PUSH配信(リアルタイム配信)する銘柄の登録・解除。登録した銘柄は
kabuステーションの「API登録銘柄リスト」(APIインジケーター右クリック)で確認できる。

### 登録

```
PUT /register
X-API-KEY: (トークン)
Content-Type: application/json

{"Symbols": [{"Symbol": "9433", "Exchange": 1}]}
```

### 解除(指定した銘柄のみ)

```
PUT /unregister
X-API-KEY: (トークン)
Content-Type: application/json

{"Symbols": [{"Symbol": "9433", "Exchange": 1}]}
```

### 全解除

```
PUT /unregister/all
X-API-KEY: (トークン)
```

(リクエストボディなし)

### レスポンス

登録・解除とも、成功時は**現在登録されている銘柄のリスト**が返る:

```json
{"RegistList": [{"Symbol": "9433", "Exchange": 1}]}
```

- 全解除が正常に行われた場合、`RegistList` は空リスト
- 全解除でエラー等が発生した場合は、現在登録されている銘柄のリストが返る

## よく見るエラー(エラーコード一覧.md より)

| HTTP | 意味 |
|---|---|
| 401 | 認証エラー(トークン不正など) |
| 429 | スロットリング制限エラー(リクエストの投げすぎ) |

| コード | 意味 |
|---|---|
| 4001007 | ログイン認証エラー → kabuステーションにログインしているか確認 |

※接続自体が拒否される(ポート18080が閉じている)場合は、kabuステーションが
起動していない・ログインしていない状態。
