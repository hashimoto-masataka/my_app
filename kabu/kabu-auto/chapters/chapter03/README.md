# 第3章 完成サンプル

第3章を終えた時点の作業フォルダです（第2章のファイルも含む）。

| ファイル | 何をするか | 節 |
|---|---|---|
| `get_prices.py` | 複数銘柄の株価を一覧表示。**0.15秒の待ち時間と、429/5xx/接続エラーのみ 1→2→4秒でリトライ** | 3-5 |
| `docs/` | 公式開発者ポータルから取得した仕様書（`kabu_STATION_API.yaml`）、エラーコード一覧、生成した簡易マニュアル `cheatsheet.md` | 3-6 |
| `CLAUDE.md` | 「ここまでの会話で分かった前提や注意点をまとめて」で生成されたもの | 3-5 |
| （第2章のファイル） | `password_setup.*` / `check_token.py` / `get_price.py` | — |

## 使い方

```
py get_prices.py                  ← 主要10銘柄
py get_prices.py 7203 9984 6758   ← 好きな銘柄
```

## 注意

- `CLAUDE.md` は通し検証で **Claude Code 自身が書いた実物** です。教えた1行（頻度制限）以外に、
  会話の事故から自分で拾った教訓（接続拒否の見立て・時間外の値・環境変数の反映・.ps1 の BOM）が入っています（本文3-5）
- `docs/cheatsheet.md` は「仕様書を正とする」の指示で生成され、自己監査で3件の食い違いを申告したものです（本文3-6）
