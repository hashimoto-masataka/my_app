# 第2章 完成サンプル

第2章を終えた時点の作業フォルダです。

| ファイル | 何をするか | 節 |
|---|---|---|
| `password_setup.bat` / `password_setup.ps1` | APIパスワードをユーザー環境変数 `KABU_API_PASSWORD` に保存する（ダブルクリック用・Windows標準機能のみ） | 2-3 |
| `check_token.py` | kabuステーションAPI に接続できるか確認する（トークン取得のみ） | 2-3 |
| `get_price.py` | 1銘柄の現在の株価を表示する（`py get_price.py 7203`） | 2-4 |

## 使い方

1. `password_setup.bat` をダブルクリック → APIパスワードを入力
2. Claude Code（または端末）をいったん閉じて開き直す（環境変数は開いた後には反映されない）
3. kabuステーションを起動してログインした状態で `py check_token.py`
4. `py get_price.py 7203`

## 注意

- 取引時間外は「最後に付いた値」（前日の大引け）が返ります。時刻が前日15:30でも正常です（本文2-4）
- 株価を取りに行っただけで、その銘柄は kabuステーションの「銘柄登録リスト」の枠を1つ使います（本文4-6で説明）
