# 第6章 完成サンプル

第6章を最後までやると、この状態になります（第2〜4章のファイルと `docs/`・`CLAUDE.md` も同梱。第5章分は通し検証待ちで未収録）。

| ファイル | 何をするか | 章 |
|---|---|---|
| `ma_signal.py` | 移動平均クロスで売買シグナルを出す（第4章の成果物） | 4-3 |
| `backtest.py` | シグナルどおり売買したときの累積損益を計算する | 6-1 |
| `gridsearch.py` | 期間の組み合わせを総当たりして最良を探す（**罠の実演**） | 6-4 |
| `walkforward.py` | 学習期間で決めて、見ていない検証期間で試す | 6-5 |
| `transfer_test.py` | 7203で選んだ28日/90日を100銘柄に当てはめる | 6-6 |
| `regime_test.py` | 前半5年・後半5年で順位が入れ替わるかを見る | 6-6 |

## 使い方

```
py backtest.py 7203 5y
py gridsearch.py 7203 5y
py walkforward.py 7203 5y
```

`transfer_test.py` と `regime_test.py` は第4章の `scan_signals.py`（100銘柄リスト）を読みます。取得した株価は `_price_cache/` に残るので、2回目からは待ちません。

第2引数は取得する期間（`1y` `2y` `5y` `10y`）。省略すると `backtest.py`／`gridsearch.py` は1年、`walkforward.py` は5年です。

## 2年分（J-Quants無料プラン）で動かす場合

`walkforward.py` の先頭にある窓の長さを short くしてください。

```python
TRAIN_DAYS = 250  # 学習期間(営業日) ※既定は500
TEST_DAYS = 60    # 検証期間(営業日) ※既定は125
```

既定のままだと「窓が1つも作れません」と出ます（学習500＋検証125＝625営業日に対し、2年分は約488営業日しかないため）。

- 手数料・スリッページ・税金は入っていません。そこは第7章の話です。
- 終値データは Yahoo Finance の公開データから取得します（kabuステーションAPIには日足履歴が無いため）。J-Quantsで貯めたCSVを使う形に差し替えても構いません。
