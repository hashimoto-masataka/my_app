# kabuステーションAPI を使うときの前提と注意点

## 全体の前提

- kabuステーションAPI は三菱UFJ eスマート証券のAPI。ユーザーのPCで起動している
  「kabuステーション」アプリが窓口で、HTTPで `localhost` に話しかける
- 接続先は **本番環境 `http://localhost:18080/kabusapi`**(検証環境は 18081 だが未使用)
- 市場は東証(`@1`)を指定している
- **このプロジェクトでは取得系のみ。発注・注文系のAPIは呼ばない**

## APIパスワードの扱い

- パスワードは**ユーザー環境変数 `KABU_API_PASSWORD`** に保存済み
- **パスワードの値をチャット・ファイル・コマンド履歴に出さない。**
  有無や文字数の確認はよいが、値そのものは表示しない
- ユーザー自身が設定するための `password_setup.bat`(+ `password_setup.ps1`)がある。
  Windows標準機能のみで動く(Python不要)。batの中身は半角英数字のみにする決まり
- **開いた後に環境変数を設定した端末には反映されない。**スクリプト実行前に
  `$env:KABU_API_PASSWORD = [Environment]::GetEnvironmentVariable("KABU_API_PASSWORD","User")`
  でユーザー環境変数から読み込み直すと確実

## 接続とトークン

- 認証は `POST /token` に `{"APIPassword": "..."}` → 返ってきた `Token` を
  以後のリクエストの `X-API-KEY` ヘッダーに載せる
- トークンは毎回取り直す作りにしている(kabuステーションを再起動しても壊れない)
- トークンも秘密情報。画面に出すのは先頭数文字まで
- **繋がらないとき(WinError 10061 接続拒否)は、まずkabuステーション側を疑う。**
  アプリが終了している・ログインしていないとAPIの窓口(ポート18080)が閉じる。
  `Get-NetTCPConnection -LocalPort 18080 -State Listen` で待ち受けの有無を確認できる。
  実際に一度、会話の途中でアプリが終了していて接続失敗→起動し直しで復旧した

## 頻度制限とリトライ

- **情報系リクエストは1秒あたり10件程度まで**(ユーザー確認済みの制限)。
  連続で呼ぶときはリクエスト間に 0.15秒 の待ちを入れる(約6.7件/秒に抑える)
- リトライ方針:
  - **する**: HTTP 429(頻度制限)・5xx(サーバー側の一時エラー)・接続エラー/タイムアウト
    → 1秒→2秒→4秒と待ちを伸ばして最大3回
  - **しない**: HTTP 400(銘柄コード間違い等)・401(パスワード違い)など、待っても直らないもの
- 複数銘柄の取得では、1銘柄失敗しても止めずに「取得失敗」と表示して残りを続ける

## 銘柄登録リスト

- 銘柄登録リストの上限は合計50銘柄。RESTでデータを取得しただけでも自動登録され、枠を消費する。
  多数の銘柄を扱うときは、使い終わった銘柄を登録解除してから次に進むこと。

## データの読み方

- 時価は `GET /board/{銘柄コード}@1`。主なフィールド:
  `SymbolName`(銘柄名) / `CurrentPrice`(現在値) / `ChangePreviousClose`(前日比) /
  `CurrentPriceTime`(値が付いた時刻)
- **取引時間外は「最後に付いた値」(前日の大引け)が返る。**時刻が前日15:30なら正常。
  `CurrentPrice` が null のこともあるので、null チェックをしてから表示する
- 価格は float で返る(3243.0)。表示は小数点以下が0なら整数に整形する

## 実行環境の注意

- Python はインストール済みで **`py` ランチャーで動く**
- ただしユーザーは「Windows標準機能だけで動く形」を求めることがある。
  その場合は PowerShell で書く。**日本語を含む .ps1 は UTF-8(BOM付き)で保存**
  しないと PowerShell 5.1 で文字化けする
- ユーザーはプログラミングの前提知識なしで進めている。エラーメッセージは日本語で、
  原因の見当(kabuステーション未起動/パスワード違い等)まで書く

## このフォルダのファイル

- `check_token.py` — 接続確認(トークン取得のみ)
- `get_price.py` — 1銘柄の株価表示(`py get_price.py 7203`)
- `get_prices.py` — 複数銘柄の一覧表示。待ち時間・リトライ入り
  (引数なしで主要10銘柄、`py get_prices.py 7203 9984 ...` で任意指定)
- `password_setup.bat` / `password_setup.ps1` — APIパスワードの設定(ダブルクリック用)
