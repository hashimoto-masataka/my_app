# クレジット明細

月ごとのクレジットカードCSVをMac内で管理し、利用者・利用店別に集計するmacOSデスクトップアプリです。

## 主な機能

- UTF-8／UTF-8 BOM付きCSVの読み込み
- 保存前の対象月、明細件数、利用者数、取込合計、警告件数の確認
- 対象月ごとの保存と切り替え
- 利用者 × 利用店名の金額集計
- 取込時合計、除外金額、現在合計の照合
- 個別明細および複数明細の集計対象からの除外
- 除外済み明細の復元
- 同一CSVの重複取込防止
- 同月CSVを置換する際の確認

CSVと保存データを外部サーバーへ送信する処理はありません。

## 動作環境

- macOS 12以降
- Apple Silicon Mac

## ビルド

```bash
zsh scripts/build-app.sh
```

ビルド後のアプリは`dist/クレジット明細.app`、配布用アーカイブは`dist/クレジット明細.zip`に作成されます。

## テスト

```bash
swift test
```

添付CSVでも確認する場合は、環境変数`CREDIT_TEST_CSV`にCSVのパスを指定します。

## データ保存先

解析済みデータは次の場所に保存されます。

```text
~/Library/Application Support/CreditStatementApp/statements.json
```

元のCSVファイル、カード番号、カード種別、支払い情報、摘要は保存しません。ブラウザーではなくMacのローカルファイルへ保存するため、アプリを終了しても月別データと除外状態が維持されます。
